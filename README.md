# 🧠 Backend Technical Practice Repository

Repositorio personal dedicado a la práctica intensiva de pruebas técnicas backend, enfocado en arquitectura limpia, buenas prácticas, diseño escalable y estándares profesionales utilizados en entornos reales de desarrollo.

Este proyecto no es un CRUD simple.  
Es un laboratorio de arquitectura y diseño.

---

# 🎯 Objetivo

El propósito de este repositorio es:

- Practicar resolución de pruebas técnicas reales.
- Diseñar APIs REST siguiendo estándares profesionales.
- Implementar arquitectura en capas y principios SOLID.
- Aplicar seguridad con JWT y control de roles.
- Trabajar paginación, filtros y ordenamiento correctamente.
- Simular escenarios empresariales reales.
